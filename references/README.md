# Literature Tracking

Keep literature claims separate from experimental observations.

Suggested table for each relevant paper:

| Field | What to record |
|---|---|
| Citation | title, authors, venue/year, URL/DOI |
| Problem | exact research question |
| Dataset/model | experimental scope |
| Forget construction | class/sample/random/targeted |
| Entanglement definition | representation, gradient, label, other |
| Collateral-damage evidence | metric and subgroup analysis |
| Reversibility evidence | relearning / recovery setup |
| Aggregate evaluation | whether subgroup failures are visible |
| Gap left open | what this project can test |
| Reproducibility | code/data availability |

Priority literature themes:

1. retain-forget entanglement
2. reversibility of machine unlearning
3. exact retraining as a reference
4. approximate unlearning baselines
5. membership-inference evaluation
6. representation / gradient geometry

Do not record a novelty claim as established until the literature search has verified it.
